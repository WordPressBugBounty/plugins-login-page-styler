== Installation ==

1. Go to **Plugins > Add New** in your WordPress dashboard
2. Search for **Login Page Styler**
3. Click **Install Now**
4. Activate the plugin
5. Go to **Settings > Login Page Styler** to customize your login page

== Frequently Asked Questions ==

= Do I need coding knowledge to use this plugin? =

No. Login Page Styler is beginner-friendly and includes a visual customizer.

= How do I change the WordPress login page logo? =

You can upload your logo from **Settings > Login Page Styler > Logo Settings**.

= Can I change the WordPress login URL? =

Yes. The plugin allows you to set a custom login URL to improve security.

= How can I protect my login page from bots? =

Enable **Google reCAPTCHA** in the plugin settings.

= Does this plugin work with any WordPress theme? =

Yes. Login Page Styler works with most WordPress themes.
